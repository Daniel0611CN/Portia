Preguntas frecuentes

Claro desde
el principio.

Sin letra pequeña y sin prometerte una IA que lo sabe todo.

¿Qué datos usa Portia?+

Empezamos con los datos públicos de tu perfil de GitHub: repositorios, lenguajes, topics, README y contribuciones. Tú decides qué se muestra.

¿La IA inventa información?+

No debería. Las cifras las calcula el código y los textos se generan solo a partir de los hechos que seleccionas. Podrás revisar y editar cada resultado.

¿Puedo probarlo sin crear una cuenta?+

Sí. La vista previa pública de un usuario de GitHub es gratuita. Para guardar, descargar o publicar tendrás que verificar tu identidad.

¿Puedo cancelar cuando quiera?+

En el plan Pro puedes cancelar al final del periodo de facturación. Tu contenido no se borra y podrás recuperarlo si vuelves.
